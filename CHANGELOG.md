# Changelog

Release notes live on the [Releases page](https://github.com/rrvrs/jira-alerts-mcp/releases).

They are generated from merged pull requests and grouped by label, configured in
[`.github/release.yml`](.github/release.yml). That is deliberate: a hand-written
changelog in this file would be a second place to remember, and the one that
gets forgotten. Labelling a PR is something the review already does.

To get a change into the notes, label its PR — `enhancement`, `bug`, `security`,
`documentation` or `dependencies`. To keep one out, label it
`ignore-for-release`.
